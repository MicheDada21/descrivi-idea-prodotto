# descrivi-idea-prodotto

Ordina in dieci blocchi la pagina che presenta un'idea di business a chi non ha contesto, dalla tensione iniziale alle domande aperte.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Descrivi idea prodotto](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/descrivi-idea-prodotto). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install descrivi-idea-prodotto@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install descrivi-idea-prodotto@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Per avere tutte le skill della libreria installa `tutte-le-skill@ch-labs-skills`. Con altri agenti copia la cartella `skills/descrivi-idea-prodotto` tra le skill dell'agente, per esempio in `~/.codex/skills/descrivi-idea-prodotto`.
